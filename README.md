# Boîte à outils de montage Opti' FITNESS

Installation : `bash setup.sh` (crée `~/opti`).

| Outil | Rôle |
|---|---|
| `opti.py` | voix, bruitages, mixage, finition image, ralentis, rythme, contrôle qualité |
| `listen.py` | écoute locale : sons reconnus, défauts, équilibre voix/musique |
| `gem.py` | critique Gemini (clé fournie dans la conversation, jamais enregistrée ici) |
| `bank.py` | banque de sons libres de droits : `sync`, `find`, `stats` |
| `studio.py` | 24 looks, 59 transitions, musique originale, profil de style |

Sons : Kenney, Sonic Pi et uisfx sous licence CC0. Transitions shader : gl-transitions sous licence MIT.
